# Franchise AI Pipeline — Interactive Demo

**Live demo:** https://7pp9gww8zn-jpg.github.io/Franchise-AI-Pipeline/

An interactive proof-of-concept for an autonomous franchise inquiry pipeline (n8n + LLM routing):

1. **Ingestion** — inbound form / inbox / webchat webhooks
2. **Extraction** — LLM pulls territory, budget, background and timeline into structured JSON
3. **Match** — territory lookup and regional franchise kit selection
4. **Dispatch** — tone-adapted, personalised reply with the right kit attached

Pick one of the four preset prospect scenarios and click **Trigger AI Automation Pipeline** to walk through the flow.

> Demo only: names, figures and emails are fictional sample data; nothing is actually sent.
